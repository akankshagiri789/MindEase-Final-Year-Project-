# MindEase – Multimodal Mental Health Prediction and Support using Deep learning via OpenAI

## 📌 Project Overview
MindEase is an AI-powered mental health prediction and support system developed as a Final Year Major Project.  
The system analyzes user emotions and stress levels using multimodal data such as facial expressions and user interaction, then provides personalized mental health support using AI.

---

## 🚀 Features
- 😊 Facial Emotion Detection
- 🧠 Stress & Anxiety Prediction
- 💬 AI Mental Health Chatbot
- 📊 Multimodal Analysis
- 🌐 User-Friendly Web Interface
- 🤖 Personalized AI Support Responses
